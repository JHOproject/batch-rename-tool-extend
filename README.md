# 批量文件重命名工具 v1.1.2（Windows 正式版目标）

**上个版本的基础：** 整个工具界面统一使用适合马来西亚用户的简体中文，并改用高对比度浅色主题，修复 macOS 深色模式下「白底白字」的问题。包含按钮、标签、表格、下拉菜单、输入框、提示窗口和选择状态。

> macOS 用来测试同一份 Python 程序，**不是 iOS 版，也没有推出 Mac App**。正式发布目标仍是 Windows 10／11 64 位的 `.exe`。此包没有提供已验证的 Windows exe，需在 Windows 电脑打包和测试。

## 怎么启动

### 在 Mac 上测试

1. 安装 Python 3.11 或更新版本。
2. 解压 ZIP，打开「终端机」（Terminal）。
3. 输入 `cd `（后面留一个空格），将解压后的 `BatchRenameTool_v1_1_2` 文件夹拖到终端机，再按 Enter。
4. 输入：

```bash
bash run_mac.command
```

第一次会自动安装 PySide6、openpyxl、xlrd（需要网络）。后续通常可以离线启动。详细说明见 `README-macOS-测试.md`。

### 在 Windows 上启动

1. 安装 Python 3.11（64 位），安装时勾选 **Add Python to PATH**。
2. 双击 `run_windows.bat` 启动工具。
3. 需要生成 Windows exe 时，请在 Windows 电脑双击 `build_windows.bat`，打包结果位于 `dist\BatchRenameTool.exe`。

## v1.1.2｜命名规则设置的显示顺序

在「③ 规则与预览」的「展开命名规则设置」中，先显示「文件名匹配与默认格式」，再显示「按文件类型使用不同命名格式」。除上述顺序外，所有布局、操作及功能与 v1.1.1 相同。

## v1.1.1｜更大的预览区域

「③ 规则与预览」改为**优先显示结果表格**：

1. 默认收起命名规则设置，预览表格可以使用大部分画面高度。
2. 如果要编辑命名格式，按右上角 **「展开命名规则设置」**，就能修改类型规则、匹配方式、默认格式；设置内容可以上下滚动。
3. 按 **「收起规则设置 · 放大预览」**，立即恢复大表格；按 **「刷新预览」** 后也会自动收起设置，让你核对批次结果。
4. 收起设置时依然显示目前设定了几条文件类型规则，原有预览／CSV 导出／重命名／撤销机制都没有更改。

## 按文件类型使用不同格式（v1.1.0 起）

在「③ 规则与预览」先按「展开命名规则设置」，就能看到两列表格：**原文件名包含的关键字 → 对应的新文件名格式**。可按「＋ 添加类型规则」新增多行。例如：

- `岗位说明书` → `{参考值}_岗位说明书`
- `劳动合同协议` → `{参考值}_{匹配值}_劳动合同协议`

只要有类型规则，**未匹配任何类型或同时匹配多种类型都会跳过**，而不是乱套用格式；没有添加类型规则时，仍使用原有默认格式。支持保存／载入新规则，预览 CSV 会列出每个文件命中的「类型规则」。详见 `MULTI_TYPES_使用说明.md`。

## 操作步骤

1. **目标文件**：添加一个或多个文件夹，可选择是否包括子文件夹。
2. **参考资料**：导入 `.xlsx`、`.xls`、`.csv`，或直接新建资料表并手动输入。
3. **编辑资料表**：第 1 行是字段名称；可从 Excel 复制多行、多列，直接粘贴到表格，超出范围时自动扩展。支持批量复制、剪切、删除、撤销和重做。
4. **设置匹配**：为每张表选择「匹配字段」及「输出字段」。
5. **规则与预览**：按「展开命名规则设置」修改新文件名格式，点击「刷新预览」，确认后才执行重命名。找不到资料、重复匹配或文件名冲突都会标示并跳过。
6. **恢复记录**：可使用「恢复上一次批量重命名」，但如果文件内容已更改或原文件名被占用，会安全跳过。

预设格式：`{参考值}_{移除匹配值后的原文件名}`。例如 `通知书_姜江蕙.pdf` 匹配 `姜江蕙 → 31234567`，输出 `31234567_通知书.pdf`。原有扩展名不会更改。

### Excel 风格快捷键

- **Windows**：Ctrl+C／V／X、Ctrl+A、Ctrl+Z／Y；Delete 清除所选单元格。
- **Mac**：使用 Command（⌘）代替 Ctrl，例如 ⌘C、⌘V、⌘Z。
- 可使用鼠标拖选多个格子、双击或 F2 编辑。整批粘贴属于一次撤销操作。

## 使用示例

压缩包包含 `samples/参考资料示例.csv` 及 `samples/demo_targets`。先复制 `demo_targets` 到其他位置，再用工具选择复制后的文件夹并导入参考 CSV。预期会有两笔可以重命名、一笔无法匹配。

**重要：** 程序不会把用户导入的姓名、字段或原文件名强制改为简体；简体中文只用于工具本身的按钮和说明，避免改变原始数据或破坏匹配。旧项目里使用的 `{參照值}` 和 `{移除比對值後的原檔名}` 等旧版变量也继续支持。

## 安全与限制

- 工具只会修改文件名，不修改文件内容，不会移动文件，也不会覆盖已有文件。
- 预览会检查文件名冲突、找不到匹配、重复匹配；执行时还会再次确认文件没有在预览后被改动。
- 项目 `.json` 和历史记录包含未加密的文件路径及参考资料，请妥善保存。
- Excel 若已把员工编号的开头 `0` 删除，程序无法猜回原来的编号；建议将编号储存为文字格式。
- macOS 目前未进行实际桌面界面验收；Windows exe 也仍需要在 Windows 电脑完成打包与实机测试。

## 自动测试

如果已安装 pytest，在工具文件夹内执行：

```bash
python -m pytest -q tests
```

未安装 PySide6 的环境会跳过 GUI 测试。自动测试通过不等同于已完成 macOS／Windows 实际视觉验收。
