# macOS 测试说明（不是 iOS 或 Mac App 版本）

正式目标仍是 **Windows `.exe`**。Mac 只是用来启动和测试同一份 Python 源码，不需要 Xcode，也不用开发 iOS 版本。

## 启动方式

1. 安装 Python 3.11 或更新版本。
2. 解压本 ZIP，打开「终端机」（Terminal）。
3. 输入 `cd `，将解压后的 `BatchRenameTool_v1_1_2` 文件夹拖进去，再按 Enter。
4. 运行：

```bash
bash run_mac.command
```

第一次启动需要连接网络，安装 PySide6 和读取 Excel 的套件。看到桌面窗口后就可以开始测试。

## 建议测试的项目

1. **文字**：检查三个页面、按钮、菜单、确认窗口是否都以简体中文显示。
2. **对比度**：特别检查 Mac 开启「深色模式」时，按钮、输入框、下拉菜单、表格和选取状态是否能清楚看到文字。
3. **批量粘贴**：从 Excel 复制例如 100 行 × 5 列到资料表；按 ⌘V 粘贴，检查是否全部进入正确格子，⌘Z 是否能整批撤销。
4. **重命名**：先复制 `samples/demo_targets` 文件夹，再导入 `samples/参考资料示例.csv`，选择「姓名」作为匹配字段、「员工编号」作为输出字段。正常情况下预计两笔可以重命名、一笔未匹配。
5. **恢复**：在测试文件夹执行重命名后，尝试恢复上一次批量重命名。

## 注意事项

- 工具界面统一简体中文，**不会更改用户原本的文件名、员工姓名或 Excel 数据文字**。
- `run_windows.bat`、`build_windows.bat` 只能在 Windows 上执行。
- 测试时先使用文件副本，避免意外修改唯一的原始文件。
- Mac 的表格快捷键使用 Command（⌘）；不是 Ctrl。
- 目前界面尚未经过实际 Mac 设备验收；如果发生无法启动或颜色看不清楚，请提供截图及终端机错误信息。
